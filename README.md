# GoldSky Print & Media Website

Professional printing, design, and advertising services website for GoldSky Print & Media, located in Kanata, Ottawa.

## 🌐 Live Site

[https://print.goldsky.ca](https://print.goldsky.ca)

## 🚀 Features

- **Responsive Design**: Fully responsive layout optimized for all devices
- **Modern UI**: Built with Next.js 15 and Tailwind CSS
- **Portfolio Showcase**: Filterable portfolio with categories
- **Service Pages**: Detailed service offerings including:
  - Printing & Document Services
  - Design & Branding
  - Signs & Advertising
  - Custom Production & 3D Printing
- **Quote System**: Integrated quote request functionality
- **Contact Forms**: Easy-to-use contact and inquiry forms

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS 4.0
- **UI Components**: Headless UI
- **Hosting**: Cloudflare Pages

## 📦 Installation

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev

# Build for production
pnpm build

# Start production server
pnpm start
```
